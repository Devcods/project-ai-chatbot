AI Document QA

This project is a simple Retrieval Augmented Generation app.

The app lets a user upload a PDF and ask questions about it. It reads the PDF, splits the text into smaller chunks, creates embeddings, stores them in FAISS, and uses an OpenAI model to answer questions based on the retrieved context.

I also added RAGAS evaluation to check the quality of the answers.

How the Project Works

The user uploads a PDF in the Streamlit app.

The PDF is loaded using pdf_loader.py.

The text is split into smaller chunks using chunk.py.

Embeddings are created using embedding.py.

The chunks are stored in a FAISS vector store.

When the user asks a question, retrieval.py finds the most relevant chunks.

llm.py sends the question and retrieved context to the OpenAI model.

The model gives an answer based on the PDF content.

evaluate.py is used to test the quality of the RAG pipeline.

Main Files
app.py

This is the main Streamlit file. It handles the PDF upload, question input, and answer display.

pdf_loader.py

This file loads the PDF and converts it into LangChain document objects.

chunk.py

This file splits the PDF text into smaller chunks. This makes retrieval easier and helps the model use only the important parts of the document.

embedding.py

This file creates embeddings using OpenAI and stores them in a FAISS vector store.

retrieval.py

This file searches the vector store and finds the most relevant chunks for the user question.

llm.py

This file sends the question and retrieved context to the OpenAI model and generates the final answer.

evaluate.py

This file evaluates the RAG system using RAGAS metrics.

test_set.json

This file stores test questions, ground truth answers, generated answers, and contexts for evaluation.

requirements.txt

This file contains the Python libraries needed for the project.

RAGAS Evaluation

RAGAS is used to check how well the RAG system is working.

This project uses four RAGAS metrics.

Faithfulness

This checks if the answer is supported by the retrieved context.

Answer Relevancy

This checks if the answer is related to the question.

Context Precision

This checks if the retrieved chunks are useful.

Context Recall

This checks if the retrieved chunks contain the important information needed to answer the question.

Running Evaluation

To run the evaluation, update test_set.json with your test questions and answers.
Then run this command.
python evaluate.py

Test Set Format

The test_set.json file should follow this format.
[
  {
    "question": "What is the main topic of the document?",
    "ground_truth": "The document explains artificial intelligence fundamentals.",
    "answer": "The document is about artificial intelligence.",
    "contexts": [
      "Artificial intelligence is the simulation of human intelligence."
    ]
  }
]
question

This is the question used for testing.

ground_truth

This is the correct answer based on the document.

answer

This is the answer generated by the model.

contexts

These are the retrieved text chunks used by the model to answer the question.
